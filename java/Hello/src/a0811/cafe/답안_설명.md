# 문제 3 답안 — 카페 메뉴 주문 관리 시스템

## 실행 방법

```bash
cd d:\junsuk3\java\Hello\src
javac a0811/cafe/*.java
java a0811.cafe.CafeApp
```

## 도서 관리 시스템과의 대응

| 도서 관리 | 카페 주문 |
|-----------|-----------|
| `Library` | `Menu` |
| `LibraryManger` | `MenuManager` |
| `Search` | `CafeApp` |
| `book()` | `order()` |
| `bookLocation` | `orderList` |
| ISBN | menuId (메뉴 코드) |

## 핵심 포인트

- `order(String name)` / `order()` 메서드 오버로딩
- 주문(품절)된 메뉴는 삭제 불가
- `price`는 `int` 타입으로 가격 관리

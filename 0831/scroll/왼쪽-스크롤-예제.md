# 왼쪽 스크롤 예제

스크롤 위치에 따라 **화면 밖에 숨어 있던 요소가 왼쪽(또는 오른쪽)에서 들어와 보이는** 애니메이션입니다.

핵심 흐름은 항상 같습니다.

1. CSS로 요소를 화면 밖(`left: -값`)에 숨긴다.
2. `$(window).scroll()`으로 현재 스크롤 값(`scrollTop`)을 읽는다.
3. 특정 위치에 도달하면 `animate()` 또는 클래스 추가로 원래 자리로 이동시킨다.

---

## 1. 미리 알아둘 API

| API | 역할 |
|---|---|
| `$(window).scrollTop()` | 화면이 문서 맨 위에서 몇 px 내려왔는지 |
| `$('.box').offset().top` | 요소가 문서 맨 위에서 몇 px 떨어져 있는지 |
| `$('.box').offset().left` | 요소가 문서 맨 왼쪽에서 몇 px 떨어져 있는지 |
| `.animate({ left: '50%' }, 800)` | JS로 위치를 부드럽게 이동 |
| `.addClass('on')` + CSS `transition` | 클래스로 위치를 부드럽게 이동 |

실습 확인용 파일: `offset.html`

```js
let abox = $('.box1').offset().top;   // 위에서부터의 거리
let cbox = $('.box3').offset().left;  // 왼쪽에서부터의 거리
console.log(abox, cbox);
```

브라우저를 열고 개발자 도구 콘솔에서 숫자를 확인하면, 이후 스크롤 조건(`if (sct >= 450)`)을 잡는 기준이 됩니다.

---

## 2. 기본 예제 — 박스를 왼쪽에서 밀어 넣기 (`scroll1.html`)

가장 단순한 형태입니다. 박스를 화면 왼쪽에 숨겨 두고, 스크롤하면 가운데로 들어옵니다.

### 2-1. CSS: 왼쪽에 숨기기

```css
.box { width: 150px; height: 150px; }

/* 화면 왼쪽 밖에 숨김 (자기 너비만큼 밀어냄) */
.box1 { background: aqua;      position: absolute; top: 300px;  left: -150px; }
.box2 { background: blueviolet; position: absolute; top: 1200px; left: -150px; }

/* 화면 오른쪽 밖에 숨김 */
.box3 { background: brown; position: absolute; top: 1800px; right: -200px; }

/* 클래스 on이 붙으면 CSS transition으로 이동 */
.box4 { background: coral; position: absolute; top: 2800px; right: -200px; transition: right 0.3s; }
.box4.on { right: 500px; }

.sTop { position: fixed; } /* 현재 스크롤 값 표시 */
```

`left: -150px`은 박스 너비(150px)만큼 왼쪽으로 밀어 화면 밖으로 보낸 값입니다.  
처음에는 안 보이다가, 스크롤 조건이 맞으면 `left: 50%`로 바뀌며 화면 안으로 들어옵니다.

### 2-2. JS: 스크롤 값에 따라 이동

```js
$(window).scroll(function () {
    var sct = $(window).scrollTop(); // 현재 스크롤 위치
    $('.sTop').text(sct);            // 화면에 숫자 표시 (디버깅용)

    if (sct >= 10) {
        $('.box1').stop().animate({ left: '50%' }, 800);
    }
    if (sct >= 500) {
        $('.box2').stop().animate({ left: '50%' }, 800);
    }
    if (sct >= 1200) {
        $('.box3').stop().animate({ right: '50%' }, 800);
    }

    if (sct <= 1500) {
        $('.box4').removeClass('on'); // 위로 올리면 다시 숨김
    }
    if (sct >= 2000) {
        $('.box4').addClass('on');    // CSS transition으로 등장
    }
});
```

포인트

- `.stop()`은 스크롤을 빠르게 내릴 때 애니메이션이 큐에 쌓여 버벅이지 않게 합니다.
- box1 ~ box3은 **jQuery `animate()`** 로 이동합니다.
- box4는 **클래스 + CSS `transition`** 으로 이동합니다. 이 방식이 이후 예제의 기본이 됩니다.
- 고정된 `h1.sTop`에 스크롤 숫자가 찍히므로, “몇 px에서 박스가 들어오는지” 눈으로 확인할 수 있습니다.

## 3. 응용 예제 — 섹션 박스가 왼쪽/오른쪽에서 등장 (`scroll3.html`)

한 화면(`100vh`) 단위 섹션 안에서, 왼쪽 카드와 오른쪽 카드가 각각 슬라이드됩니다.

관련 파일

- `scroll3.html`
- `css/scroll3.css`
- `js/scroll3.js`

### 3-1. HTML 구조

```html
<div class="section section2">
    <div class="left1">
        <h1>밥</h1>
        <p>삼겹살</p>
    </div>
    <div class="right1">
        <h1>밥2</h1>
        <p>치킨</p>
    </div>
</div>
```

`.left1`은 왼쪽에서, `.right1`은 오른쪽에서 들어옵니다.

### 3-2. CSS: 화면 밖에 숨긴 뒤, `.on`이면 안으로

```css
.section2 .left1 {
    position: absolute;
    padding: 50px;
    background-color: #fff;
    text-align: center;
    top: 50px;
    left: -350px;          /* 왼쪽 화면 밖 */
    transition: all 0.3s;
}
.section2 .left1.on {
    left: 100px;           /* 화면 안으로 이동 */
}

.section2 .right1 {
    position: absolute;
    padding: 50px;
    background-color: #fff;
    text-align: center;
    bottom: 50px;
    right: -350px;         /* 오른쪽 화면 밖 */
    transition: all 0.3s;
}
.section2 .right1.on {
    right: 100px;
}
```

JS에서 위치 숫자를 직접 바꾸지 않습니다.  
**클래스만 붙였다 뗐다** 하면 CSS `transition`이 움직임을 담당합니다.

### 3-3. JS: 스크롤 구간에만 클래스 부여

```js
$(function () {
    $(window).scroll(function () {
        let sct = $(this).scrollTop();
        $('.s_Top').text(sct);

        // 450 ~ 1000px : 왼쪽 박스 등장
        if (sct >= 450 && sct <= 1000) {
            $('.left1').addClass('on');
        } else {
            $('.left1').removeClass('on');
        }

        // 1000 ~ 1800px : 오른쪽 박스 등장
        if (sct >= 1000 && sct <= 1800) {
            $('.right1').addClass('on');
        } else {
            $('.right1').removeClass('on');
        }
    });
});
```

구간을 `>=` 와 `<=` 로 묶었기 때문에, **해당 섹션을 지나면 다시 화면 밖으로 나갑니다.**  
스크롤을 위로 올려도 애니메이션이 반복되어 학습·데모에 좋습니다.

스크롤 값 표시 요소는 HTML의 `h1.s_Top` 입니다. 선택자는 `$('.s_Top')` 처럼 클래스 앞에 점(`.`)이 필요합니다.

## 4. 동작 원리 한눈에 보기

```
페이지 로드
    │
    ▼
.left1 { left: -350px }     ← 화면 왼쪽 밖에 숨김
    │
    ▼
사용자가 스크롤
    │
    ▼
sct = $(window).scrollTop()  ← 현재 위치(px) 읽기
    │
    ├─ sct가 450 ~ 1000 사이인가?
    │       YES → addClass('on')  → left: 100px  (왼쪽에서 슬라이드 인)
    │       NO  → removeClass('on') → left: -350px (다시 숨김)
    │
    └─ 오른쪽 박스(.right1)도 같은 방식으로 right 값을 바꿈
```

왼쪽 스크롤의 핵심은 **`left` 음수 → 양수(또는 %) 전환** 입니다.  
오른쪽은 `right`로 같은 일을 하면 됩니다.

---

## 5. 두 가지 움직이는 방법 비교

| | jQuery `animate()` (`scroll1`) | 클래스 + `transition` (`scroll3`) |
|---|---|---|
| 위치 변경 | JS에서 `{ left: '50%' }` | CSS에서 `.on { left: 100px }` |
| 속도 조절 | `animate(..., 800)` | `transition: all 0.3s` |
| 되돌리기 | 다시 `animate({ left: '-150px' })` | `removeClass('on')` |
| 권장 | 간단한 한 번 등장 | 반복 등장, 유지보수에 유리 |

실무에서는 **클래스 + CSS transition** 을 더 많이 씁니다. JS는 “언제 켤지”만 결정하고, “어떻게 움직일지”는 CSS에 맡깁니다.

## 6. 이어서 보면 좋은 예제

같은 폴더의 나머지 파일은 왼쪽 스크롤을 확장한 버전입니다.

### `scroll2.html` — 페이드 인

이미지를 `opacity: 0`으로 숨기고, 스크롤 시 `.on`을 붙여 `opacity: 1`로 보여 줍니다.  
위치(`left`)가 아니라 **투명도**만 바꾼 변형입니다.

```css
.container > div > img { opacity: 0; transition: all 0.8s; }
.container > div.on > img { opacity: 1; margin-top: 20px; }
```

### `scroll4.html` — 왼쪽 스크롤 + 고정 메뉴

`scroll3`에 내비게이션이 추가됩니다.

- 스크롤 100px 이상 → `nav`에 `.fixed` (상단 고정, 배경 불투명)
- 각 섹션 `offset().top`과 비교해 해당 메뉴에 `.on`
- 메뉴 클릭 시 `animate({ scrollTop: 해당섹션위치 }, 1000)` 으로 이동

```js
$('nav ul li').click(function () {
    var i = $(this).index();
    var offset_t = $('.container > div').eq(i).offset().top;
    $('html, body').stop().animate({ scrollTop: offset_t }, 1000);
    return false;
});
```

가로 스크롤이 생기지 않도록 CSS에 `body { overflow-x: hidden; }` 이 들어가 있습니다.  
왼쪽/오른쪽으로 숨긴 요소(`left: -350px`) 때문에 가로 바가 생기는 것을 막습니다.

## 7. 직접 바꿔 보면 좋은 값

| 바꿀 곳 | 효과 |
|---|---|
| `left: -350px` | 숨는 거리. 절댓값이 클수록 더 멀리서 들어옴 |
| `left: 100px` (`.on`) | 도착 위치 |
| `transition: all 0.3s` | 슬라이드 속도 |
| `sct >= 450 && sct <= 1000` | 등장하는 스크롤 구간 |
| `body { overflow-x: hidden; }` | 숨긴 요소 때문에 가로 스크롤이 생길 때 |

연습 순서 추천

1. `offset.html`에서 `offset().top` / `offset().left` 숫자 확인
2. `scroll1.html`에서 왼쪽 박스(`box1`, `box2`)만 먼저 동작시키기
3. `scroll3.html`에서 `.left1`의 `left` 값과 스크롤 구간을 바꿔 보기
4. `scroll4.html`에서 메뉴 클릭 이동까지 연결해 보기

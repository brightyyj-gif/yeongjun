# 문제 2 답안 — 학원 수강생 관리 시스템

## 실행 방법

```bash
cd d:\junsuk3\java\Hello\src
javac a0811/academy/*.java
java a0811.academy.AcademyApp
```

## 도서 관리 시스템과의 대응

| 도서 관리 | 학원 수강 |
|-----------|-----------|
| `Library` | `Student` |
| `LibraryManger` | `StudentManager` |
| `Search` | `AcademyApp` |
| `available` (대출 가능) | `enrolled` (수강 여부, 기본 false) |
| `book()` | `enroll()` |
| `bookLocation` | `enrolledList` |

## 핵심 포인트

- `enrolled == false` → 수강 가능한 학생 (메뉴 1)
- `enrolled == true` → 수강 중인 학생 (메뉴 3)
- 수강 중인 학생은 삭제 불가

# 도서 관리 시스템 형식 연습문제

아래 3개 문제는 `Library` + `LibraryManger` + `Search` 구조와 동일한 형식입니다.  
각 문제마다 **모델 클래스 1개 + 관리 클래스 1개 + main 클래스 1개**로 구현하세요.

---

## 공통 요구사항

- `ArrayList`로 목록 관리
- 생성자에서 **더미 데이터 3개** 미리 등록
- `Scanner`로 메뉴 입력, `switch`로 분기
- `equalsIgnoreCase()`로 이름 검색 (대소문자 무시)
- `toString()` 오버라이드
- 메서드 **오버로딩** 1회 이상 사용
- 숫자 입력 후 `sc.nextLine()`으로 버퍼 비우기

## 문제 1. 영화 대여 관리 시스템

**패키지:** `a0811.movie`

### 클래스 구성

| 클래스 | 역할 |
|--------|------|
| `Movie.java` | 영화 1편 정보 |
| `MovieManager.java` | 영화 목록 및 대여 관리 |
| `MovieApp.java` | 메뉴 및 main |

### Movie 필드

| 필드 | 타입 | 설명 |
|------|------|------|
| `title` | String | 영화 제목 |
| `director` | String | 감독 |
| `genre` | String | 장르 |
| `rating` | String | 관람 등급 |
| `available` | boolean | 대여 가능 여부 |

### 더미 데이터

| 제목 | 감독 | 장르 | 등급 |
|------|------|------|------|
| Inception | Nolan | SF | 12 |
| Parasite | Bong | Drama | 15 |
| Toy Story | Lasseter | Animation | All |

### 메뉴

```
1. 대여 가능한 영화 보기
2. 영화 대여하기
3. 대여한 영화 보기
4. 영화 추가하기
5. 영화 삭제하기
6. 영화 정보 수정하기
7. 영화 내용 보기
8. 종료
```

### 구현 힌트

- `rent(String title)` : 대여 처리, `rentedList`에 추가, `true/false` 반환
- `rent()` : 대여 목록 출력 (오버로딩)
- `deleteMovie()` : **대여 중인 영화는 삭제 불가**
- `updateMovie()` : 제목/감독/장르/등급 중 선택 수정

## 문제 2. 학원 수강생 관리 시스템

**패키지:** `a0811.academy`

### 클래스 구성

| 클래스 | 역할 |
|--------|------|
| `Student.java` | 수강생 1명 정보 |
| `StudentManager.java` | 수강생 목록 및 등록 관리 |
| `AcademyApp.java` | 메뉴 및 main |

### Student 필드

| 필드 | 타입 | 설명 |
|------|------|------|
| `name` | String | 학생 이름 |
| `course` | String | 수강 과목 |
| `phone` | String | 연락처 |
| `grade` | int | 최근 시험 점수 |
| `enrolled` | boolean | 수강 등록 여부 (`true`: 수강 중) |

### 더미 데이터

| 이름 | 과목 | 연락처 | 점수 |
|------|------|--------|------|
| Kim Minsoo | Java | 010-1111-2222 | 85 |
| Lee Jieun | Python | 010-3333-4444 | 92 |
| Park Junho | Web | 010-5555-6666 | 78 |

### 메뉴

```
1. 수강 가능한 학생 보기      (enrolled == false)
2. 수강 등록하기
3. 수강 중인 학생 보기        (enrolled == true)
4. 학생 추가하기
5. 학생 삭제하기              (수강 중이면 삭제 불가)
6. 학생 정보 수정하기         (이름/과목/연락처/점수)
7. 학생 정보 조회하기
8. 종료
```

### 구현 힌트

- `enroll(String name)` : 수강 등록, `enrolledList`에 추가
- `enroll()` : 수강 중 목록 출력 (오버로딩)
- `book()` 대신 `enroll()` 메서드로 `enrolled = true` 변경

## 문제 3. 카페 메뉴 주문 관리 시스템

**패키지:** `a0811.cafe`

### 클래스 구성

| 클래스 | 역할 |
|--------|------|
| `Menu.java` | 메뉴 1개 정보 |
| `MenuManager.java` | 메뉴 목록 및 주문 관리 |
| `CafeApp.java` | 메뉴 및 main |

### Menu 필드

| 필드 | 타입 | 설명 |
|------|------|------|
| `name` | String | 메뉴 이름 |
| `price` | int | 가격 |
| `category` | String | 카테고리 (Coffee, Dessert 등) |
| `menuId` | String | 메뉴 코드 |
| `available` | boolean | 주문 가능 여부 |

### 더미 데이터

| 이름 | 가격 | 카테고리 | 코드 |
|------|------|----------|------|
| Americano | 4500 | Coffee | M001 |
| Latte | 5000 | Coffee | M002 |
| Cheesecake | 6500 | Dessert | M003 |

### 메뉴

```
1. 주문 가능한 메뉴 보기
2. 메뉴 주문하기
3. 주문한 메뉴 보기
4. 메뉴 추가하기
5. 메뉴 삭제하기
6. 메뉴 정보 수정하기
7. 메뉴 내용 보기
8. 종료
```

### 구현 힌트

- `order(String name)` : 주문 처리, `orderList`에 추가
- `order()` : 주문 목록 출력 (오버로딩)
- `toString()`에 가격을 `"4,500원"` 형식으로 출력해도 좋음 (선택)

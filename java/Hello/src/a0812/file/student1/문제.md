# 파일 입출력 연습 문제

아래는 `student1` 예제(Student / StudentSave / StudentRead)와 **같은 구조**로 풀어 보세요.

공통 요구사항
1. 정보를 담는 **클래스** 1개 (필드 + 생성자 + getter)
2. 객체를 배열로 만들고 **파일에 저장**하는 클래스 1개 (`File`, `FileWriter`)
3. 저장된 파일을 **읽어서 출력**하는 클래스 1개 (`FileReader`)
4. 폴더가 없으면 `mkdir()`로 생성
5. 저장/읽기 시 예외 처리 (`try-catch`)

저장 경로 예: `C:/abcdf/` (폴더명은 자유롭게 변경 가능)

---

## 문제 1. 도서 (Book)

도서 정보를 파일로 저장하고 다시 읽어 출력하는 프로그램을 작성하시오.

### 1-1. `Book` 클래스
| 필드 | 타입 | 설명 |
|------|------|------|
| title | String | 제목 |
| author | String | 저자 |
| price | int | 가격 |

- 생성자로 세 값을 초기화
- 각 필드에 대한 getter 작성

### 1-2. `BookSave` 클래스
다음 3권의 도서를 배열로 만들고 `C:/abcdf/book.txt`에 저장하시오.

| 제목 | 저자 | 가격 |
|------|------|------|
| 자바의 정석 | 남궁성 | 30000 |
| 혼자 공부하는 자바 | 신용권 | 25000 |
| Clean Code | Robert Martin | 35000 |

저장 형식 예:
```
===== 도서 정보 =====
제목 : 자바의 정석
저자 : 남궁성
가격 : 30000
```

- 저장 성공 시 `"도서 정보 저장 완료"` 출력
- 실패 시 `"저장 실패"` 출력

### 1-3. `BookRead` 클래스
`C:/abcdf/book.txt`를 읽어 콘솔에 출력하시오.
- 실패 시 `"파일을 읽을 수 없습니다."` 출력

## 제출 / 확인 방법
1. Save 클래스 실행 → txt 파일 생성 확인
2. Read 클래스 실행 → 콘솔에 저장된 내용이 그대로 출력되는지 확인
3. 폴더가 없을 때도 Save가 폴더를 자동 생성하는지 확인

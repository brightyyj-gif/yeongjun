# 파일 입출력 연습 문제 — 정답

패키지명은 예시입니다. `student1`과 같이 원하는 패키지로 바꿔도 됩니다.

---

## 문제 1. 도서 (Book) 정답

### Book.java

```java
package a0812.file.book1;

public class Book {
    private String title;
    private String author;
    private int price;

    public Book(String title, String author, int price) {
        this.title = title;
        this.author = author;
        this.price = price;
    }

    public String getTitle() {
        return title;
    }

    public String getAuthor() {
        return author;
    }

    public int getPrice() {
        return price;
    }
}
```

### BookSave.java

```java
package a0812.file.book1;

import java.io.File;
import java.io.FileWriter;

public class BookSave {
    public static void main(String[] args) {
        Book[] books = {
                new Book("자바의 정석", "남궁성", 30000),
                new Book("혼자 공부하는 자바", "신용권", 25000),
                new Book("Clean Code", "Robert Martin", 35000)
        };

        File folder = new File("C:/abcdf");

        if (!folder.exists()) {
            folder.mkdir();
        }

        File file = new File("C:/abcdf/book.txt");

        try {
            FileWriter fw = new FileWriter(file);
            for (Book b : books) {
                fw.write("===== 도서 정보 =====\n");
                fw.write("제목 : " + b.getTitle() + "\n");
                fw.write("저자 : " + b.getAuthor() + "\n");
                fw.write("가격 : " + b.getPrice() + "\n");
            }
            fw.close();
            System.out.println("도서 정보 저장 완료");
        } catch (Exception e) {
            System.out.println("저장 실패");
        }
    }
}
```

### BookRead.java

```java
package a0812.file.book1;

import java.io.FileReader;
import java.io.IOException;

public class BookRead {
    public static void main(String[] args) {
        try {
            FileReader fr = new FileReader("C:/abcdf/book.txt");
            int ch;
            while ((ch = fr.read()) != -1) {
                System.out.print((char) ch);
            }
            fr.close();
        } catch (IOException e) {
            System.out.println("파일을 읽을 수 없습니다.");
        }
    }
}
```

### TravelSave.java

## 문제 3. 영화 (Movie) 정답

### Movie.java

```java
package a0812.file.movie1;

public class Movie {
    private String title;
    private String director;
    private int year;

    public Movie(String title, String director, int year) {
        this.title = title;
        this.director = director;
        this.year = year;
    }

    public String getTitle() {
        return title;
    }

    public String getDirector() {
        return director;
    }

    public int getYear() {
        return year;
    }
}
```

### MovieSave.java

```java
package a0812.file.movie1;

import java.io.File;
import java.io.FileWriter;
```

## 핵심 흐름 (student1과 동일)

1. **도메인 클래스** — 필드, 생성자, getter
2. **Save** — 객체 배열 → 폴더 생성 → `FileWriter`로 텍스트 저장
3. **Read** — `FileReader`로 한 글자씩 읽어 콘솔 출력

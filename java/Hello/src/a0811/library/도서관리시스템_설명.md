# 도서 관리 시스템 (Library Management System)

## 1. 개요

이 프로그램은 **콘솔(터미널) 기반 도서 관리 시스템**입니다.  
도서의 조회, 대출, 추가, 삭제, 수정 기능을 제공하며, Java의 **객체지향 프로그래밍(OOP)** 개념을 활용해 3개의 클래스로 구성되어 있습니다.

| 파일 | 역할 |
|------|------|
| `Library.java` | 도서 한 권의 정보를 담는 **데이터 모델(VO)** |
| `LibraryManger.java` | 도서 목록을 관리하는 **비즈니스 로직** |
| `Search.java` | 사용자와 상호작용하는 **메인 프로그램(진입점)** |

패키지: `a0811.library`

---

## 2. 전체 구조

```
Search (main)
    │
    └── LibraryManger (관리자)
            │
            ├── librarys (ArrayList) ── 전체 도서 목록
            │
            └── bookLocation (ArrayList) ── 대출된 도서 목록
                    │
                    └── Library (도서 객체)
                            ├── title    (책 이름)
                            ├── author   (저자)
                            ├── location (보관 위치)
                            ├── isbn     (ISBN 번호)
                            └── available (대출 가능 여부)
```

### 실행 흐름

1. `Search.main()` 실행 → `LibraryManger` 객체 생성
2. 생성자에서 **더미 데이터 3권** 자동 등록
3. 무한 루프(`while`)로 메뉴 출력 → 사용자 입력 처리
4. 선택한 메뉴에 따라 `LibraryManger`의 메서드 호출
5. 8번(종료) 선택 시 프로그램 종료

---

## 3. 클래스별 상세 설명

### 3.1 Library.java — 도서 정보 클래스

도서 한 권의 속성과 기본 동작을 정의하는 **값 객체(Value Object)** 입니다.

#### 필드 (멤버 변수)

| 필드 | 타입 | 설명 |
|------|------|------|
| `title` | `String` | 도서 제목 |
| `author` | `String` | 저자 |
| `location` | `String` | 도서관 내 보관 위치 (예: SectionA) |
| `isbn` | `String` | ISBN 번호 |
| `available` | `boolean` | 대출 가능 여부 (`true`: 대출 가능, `false`: 대출 중) |

#### 생성자

- **기본 생성자** `Library()`  
  필드를 초기화하지 않는 빈 생성자입니다.

- **매개변수 생성자** `Library(title, author, location, isbn)`  
  도서 정보 4가지를 받아 객체를 생성하고, `available`은 자동으로 `true`(대출 가능)로 설정합니다.

#### 주요 메서드

| 메서드 | 설명 |
|--------|------|
| `getTitle()`, `setTitle()` | 제목 조회/수정 |
| `getAuthor()`, `setAuthor()` | 저자 조회/수정 |
| `getLocation()`, `setLocation()` | 위치 조회/수정 |
| `getIsbn()`, `setIsbn()` | ISBN 조회/수정 |
| `isAvailable()`, `setAvailable()` | 대출 가능 여부 조회/수정 |
| `book()` | **대출 처리** — `available`을 `false`로 변경 |
| `toString()` | 도서 정보를 한 줄 문자열로 반환 |

#### toString() 출력 형식

```
책이름 : {title}, 저자={author}, 책 위치={location}, ISBN={isbn}{대출가능|대출불가능}
```

예시:
```
책이름 : this is java, 저자=shin, 책 위치=SectionA, ISBN=979-11-691-229-8대출가능
```

### 3.2 LibraryManger.java — 도서 관리 클래스

도서 목록의 CRUD(생성·조회·수정·삭제)와 대출/반납 상태를 관리하는 **핵심 로직 클래스**입니다.

> 클래스명이 `Manager`가 아닌 `Manger`로 작성되어 있습니다.

#### 필드

| 필드 | 타입 | 설명 |
|------|------|------|
| `librarys` | `ArrayList<Library>` | **전체 도서 목록** |
| `bookLocation` | `ArrayList<Library>` | **현재 대출 중인 도서 목록** |

#### 생성자 — 초기 더미 데이터

프로그램 시작 시 아래 3권의 도서가 자동으로 등록됩니다.

| 제목 | 저자 | 위치 | ISBN |
|------|------|------|------|
| this is java | shin | SectionA | 979-11-691-229-8 |
| First React | Lee Inje | Section B | 979-11-6921-169-7 |
| Web Standards | Ko Kyunghee | Section C | 979-11-6303-622-7 |

#### 메서드 상세

##### `allLibrary()` — 대출 가능한 도서 보기

- `librarys` 리스트를 순회합니다.
- `isAvailable()`이 `true`인 도서만 출력합니다.
- 이미 대출된 도서는 목록에 나타나지 않습니다.

##### `bookLocations(String libraryName)` — 도서 대출하기

- 입력받은 도서명(`libraryName`)과 **대소문자 구분 없이**(`equalsIgnoreCase`) 일치하는 도서를 찾습니다.
- 해당 도서가 **대출 가능**(`available == true`)이면:
  1. `library.book()` 호출 → 대출 불가 상태로 변경
  2. `bookLocation` 리스트에 추가
  3. `true` 반환 (대출 성공)
- 도서가 없거나 이미 대출 중이면 `false` 반환

##### `bookLocations()` — 대출한 도서 보기 (오버로딩)

- 매개변수가 없는 **동일 이름의 다른 메서드**입니다. (메서드 오버로딩)
- `bookLocation` 리스트에 저장된 대출 중인 도서를 모두 출력합니다.

##### `addLibrary(title, author, location, isbn)` — 도서 추가

- 새 `Library` 객체를 생성하여 `librarys` 리스트에 추가합니다.
- 새로 추가된 도서는 기본적으로 대출 가능(`available = true`) 상태입니다.

##### `delLibrary(dname)` — 도서 삭제

- 도서명으로 검색하여 삭제합니다.
- **대출 가능한 도서만** 삭제할 수 있습니다.
  - 대출 중(`available == false`)인 도서는 삭제되지 않습니다.
- 결과 메시지:
  - `"삭제됨"` — 삭제 성공
  - `"삭제안됨"` — 도서 없음 또는 대출 중

##### `updateLibrary(uname)` — 도서 정보 수정

- 도서명으로 검색 후, 수정 항목을 선택합니다.

  | 번호 | 수정 항목 |
  |------|-----------|
  | 1 | 도서 이름 |
  | 2 | 도서 저자 |
  | 3 | 도서 위치 |
  | 4 | 도서 ISBN |

- 해당 도서를 찾지 못하면 `"찾는 도서가 없어서 업데이트 할 수 없습니다."` 출력

##### `showLibrary(sname)` — 도서 내용 보기

- 도서명으로 검색하여 해당 도서의 상세 정보(`toString()`)를 출력합니다.
- 대소문자 구분 없이 검색합니다.

### 3.3 Search.java — 메인 프로그램 (진입점)

사용자 입력을 받아 메뉴를 표시하고, `LibraryManger`의 기능을 호출하는 **UI(사용자 인터페이스) 클래스**입니다.

#### 실행 방법

```bash
javac a0811/library/*.java
java a0811.library.Search
```

#### 메뉴 구성

```
 도서검색 시스템에 오신 것을 환영합니다.
1.대출 가능한 도서 보기
2.도서 대출하기
3.대출한 도서 보기
4.도서 추가하기
5.도서 삭제하기
6.도서 정보 수정하기
7.도서 내용 보기
8.종료
원하는 작업을 선택하세요 >>
```

| 메뉴 | 기능 | 호출 메서드 |
|------|------|-------------|
| 1 | 대출 가능한 도서 목록 출력 | `manger.allLibrary()` |
| 2 | 도서 대출 (도서명 입력) | `manger.bookLocations(도서명)` |
| 3 | 대출 중인 도서 목록 출력 | `manger.bookLocations()` |
| 4 | 새 도서 등록 (이름, 저자, 위치, ISBN 입력) | `manger.addLibrary(...)` |
| 5 | 도서 삭제 (도서명 입력) | `manger.delLibrary(도서명)` |
| 6 | 도서 정보 수정 (도서명 입력 후 항목 선택) | `manger.updateLibrary(도서명)` |
| 7 | 특정 도서 상세 조회 (도서명 입력) | `manger.showLibrary(도서명)` |
| 8 | 프로그램 종료 | `flag = false` |

#### 입력 처리 방식

- `Scanner` 클래스로 키보드 입력을 받습니다.
- 숫자 입력(`nextInt()`) 후 `sc.nextLine()`으로 **입력 버퍼를 비워** 다음 문자열 입력이 정상 동작하도록 처리합니다.
- 메뉴 5, 6, 7에서는 빈 문자열 입력 시 재입력을 요청합니다.

## 4. 사용 예시

### 4.1 대출 가능한 도서 보기 (메뉴 1)

```

책이름 : this is java, 저자=shin, 책 위치=SectionA, ISBN=979-11-691-229-8대출가능

```

→ `this is java`의 `available`이 `false`로 변경되고, 메뉴 1에서는 더 이상 보이지 않습니다.

## 5. 핵심 Java 개념

이 프로그램에서 사용된 주요 Java 개념은 다음과 같습니다.

| 개념 | 적용 위치 | 설명 |
|------|-----------|------|
| **클래스와 객체** | `Library` | 도서 정보를 캡슐화한 객체 |
| **캡슐화** | `private` 필드 + getter/setter | 데이터를 외부에서 직접 접근하지 않음 |
| **ArrayList** | `LibraryManger` | 동적 크기의 도서 목록 관리 |
| **메서드 오버로딩** | `bookLocations()` | 같은 이름, 다른 매개변수 |
| **향상된 for문** | `for(Library library : librarys)` | 컬렉션 순회 |
| **equalsIgnoreCase** | 도서명 검색 | 대소문자 구분 없는 문자열 비교 |
| **toString() 오버라이드** | `Library` | 객체를 문자열로 표현 |
| **Scanner** | `Search`, `updateLibrary` | 사용자 입력 처리 |
| **switch문** | `Search.main()` | 메뉴 분기 처리 |

## 7. 참고 사항

- **반납 기능**은 현재 구현되어 있지 않습니다. 대출된 도서는 `bookLocation`에만 저장되며, 다시 대출 가능 상태로 되돌리는 메서드는 없습니다.
- **ISBN 중복 검사**나 **도서명 중복 검사**는 없어, 동일한 도서를 여러 번 추가할 수 있습니다.
- `LibraryManger` 클래스명은 `Manager`의 철자가 `Manger`로 되어 있습니다.
- `Search.java`의 case 7(도서 내용 보기)에는 컴파일 오류가 있을 수 있습니다 (`showLibrary(sname)` 뒤 세미콜론 누락, 빈 입력 처리 시 변수명 오류).
